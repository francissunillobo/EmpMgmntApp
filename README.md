# EmpMgmtAppAng22

Employee Management system is developed using Angular 22

Modules

1. Deapartments and Child departments.. For example IT is a main department and QA, Development, Testing sub department
2. Employee onboarding
3. Client Project Listing
4. Assign Employee to the Project
5. Dashboard
6. Login

We also use bootstrap

This project management system is for service based company

APIS used from https://projectapi.gerasim.in/index.html
